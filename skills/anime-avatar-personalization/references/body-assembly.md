# 身体生成与完整头颈装配

输入为已接受的可动画头颈/头发、目标穿衣身体参考及身体生成/绑定工具。保留服装设计与头部动画结构。主入口见 [SKILL.md](../SKILL.md)。

## 1. 在生成参考时准备接口

身体参考采用完整全身 A-pose 或工具支持且能清楚分离四肢的姿态；手臂离开躯干、双腿分开、手脚/衣摆完整。生成前固定身高、头身比、肩宽、领口与模板头颈的比例关系。

可用临时无发无五官头占位，避免头发遮挡领口和生成额外身份目标。占位头不保证会独立分件，导出后仍需语义审查。

```text
依据目标角色生成同一套服装的全身三维参考。
中性 A-pose、零相机倾斜、四肢分离、完整手脚、衣摆和配饰。
精确保留领口、领子、领结、披肩及肩部衣物，不简化或改设计。
使用临时无发无五官头，其头颈比例贴近已提供的最终头颈。
领口开口清楚，便于移除占位皮肤并装入完整头颈。
无头发遮住领口，无夸张透视、文字或多视图拼版。
```

身体生成、分件、重网格、贴图和自动绑定分别记录实际输出。按当次绑定器限制设面数，不把某个工具曾用的预算当通用限制。查看真实纹理尺寸和每个材质引用，界面“2K/4K”未必代表每部件相同尺寸。

在最终绑定/减面后的源上制作语义索引；重网格会使旧顶点/三角编号失效。保存原始 GLB/FBX 与纹理 hash。

## 2. 身体进入装配前的检查

看原生四面、裸几何/材质和分件 ID：身份/服装、手指、肢体粘连、身体左右、领口/袖口、裙身、脚。实际执行抬臂、屈肘、抬腿和蹲姿，检查关节与权重牵拉。

裙装的身体自动绑定常需专门修权重或裙骨；对连续连衣裙不要未经验证直接沿腰线切断或让整件受同一弹簧控制。头发物理方案不能直接证明衣物运动有效。保留失败并安排独立衣物实验。

## 3. 配准完整头颈

先用统一尺度/平移配身体，按身高、肩宽、颈窝、领口上缘与地面校准。用实际相机和多角度检查；不要按图片裁切差异盲猜比例。

保持头、颈、眼骨、脸骨、头发及其安装结构的相对关系。脖子太长时优先评估完整头颈的刚体高度和身体尺度，避免只缩颈骨拉坏绑定。记录移动对眼球、视点与碰撞体的影响。

模板若仍包含原身体，先提取真实颈部/必要肩根表面及全部相关 shape，保留源索引与骨映射。不要将已有的喉部曲率换成无依据圆管。

## 4. 语义裁皮，保护衣领

同一生成部件可能同时含皮肤头颈、白领和领结。整件删除或水平一刀切都可能破坏服装。

1. 清点最终源的连接分量、submesh、原 UV、纹理和三角 ID。
2. 标记“需删除的占位皮肤”和“需保留的衣物”，结合结构/纹理审核；白色皮肤与白衣领不能只用亮度阈值。
3. 制作按源三角索引的保留/删除 mask，绑定源 hash。
4. 在分区诊断图与原材质四面图上确认，尤其检查高领、领结和胸口配件。
5. 只删皮肤面；保留衣服原位置、法线/切线、UV、纹理和受保护面。压缩无引用顶点时同步重映射各属性/权重。

供体颈底只裁埋在衣领中的多余肩翼。交边新增点沿原边插值位置、UV 和形状位移，合并/归一化骨影响；保留颈部原形态与材质。裁切高度和椭圆范围必须由本角色领口决定。

若本次选择通过衣领遮挡而非焊接，应明确接缝技术与适用视角，不声称水密。肤色差、硬边和低头时暴露仍需原材质检查。

## 5. 一个主骨架与正确 bindpose

保留一个主 Humanoid 和根 Animator，将生成身体骨映射到该骨架；稳定脸部/眼骨路径，清除错误的旧身体显示与重复控制。非 Humanoid 骨映射要显式记录，祖先回退也需动作测试。

源表面的世界蒙皮关系可表达为：

```text
p_world = Σ_i [w_i * boneWorld_i * sourceBindpose_i] * p_local
targetBindpose_i = inverse(targetBoneWorldRest_i) * targetRendererWorldRest
```

搬运时按源全部骨权重求当前 rest 表面，再转入目标 renderer；不只按最大影响骨搬点。法线使用正确逆转置、切线处理方向和手性，shape delta 与几何变换保持一致。

骨位置与骨轴 roll 分开核对。导出含反射/负尺度时不能机械复制 quaternion；使用明确坐标转换与已验证的轴约定，再以实际蒙皮验证。

## 6. Humanoid 参考姿态与衣领权重

若构建 Humanoid 需临时 T-pose，先保存全部原 rest 矩阵，建 Avatar 后恢复生成身体原姿态，再保存成品。对原生 BakeWorld 与源衣物逐部件比较；`isHuman=true` 不能证明衣服 rest 未被错误烘焙。

衣领若受头/手臂权重拉走，可在副本上把适当区域平滑重绑到上胸，保持几何和 UV 不动。人工修过权重就明确记录范围、原因和效果，不能计为“无需干预的自动绑定通过”。

## 7. 新进程重开与接口测试

保存并在新进程打开真实结果，核验：

- 脸部/眼骨/形态/材质及控制绑定按许可差异保持。
- 颈部仅声明的整体安放与隐藏底缘裁切，相关 shape 仍有效。
- 原衣服姿态、受保护三角/UV/纹理保持。
- 单一主 Animator、有效 Humanoid、无缺失脚本/外部骨/碰撞引用。
- 新旧头发/衣物物理的启用状态明确，发骨无重复写入。

实际测试转头、低头/仰头、侧倾、蹲起和举臂。量上口脸颈接缝与下口衣领的完整边界/间隙，并检查视觉；少数近点稳定只能说明这些点，不代表整环闭合。

身体比例变化后重新设置头/胸/肩头发碰撞体，按 [hair.md](hair.md) 重测；接着按 [validation.md](validation.md) 做组合动作和交付验证。
