# 头发生成、适配、代理权重与物理

输入为已接受的定制头颈、目标发型图及可用三维生成工具。先确定静态轮廓，再扩展骨链与物理。主入口见 [SKILL.md](../SKILL.md)。

## 1. 在已接受裸脸上生成目标

用目标角色图和已接受裸脸作为 ImageGen 输入，锁定脸部身份、姿态、相机与瞳距，仅生成头发/饰品。正面目标先确认刘海长度/分束、头顶宽度、脸框与非对称饰品侧。

```text
仅为所提供的已接受裸脸添加目标角色的头发和头饰。
保持眼睛、眉睫、鼻口、下颌、脸部比例、视线和相机不变。
严格匹配参考中的刘海尖端、分束、脸框、头顶宽度、后发长度/体积与饰品侧。
完整显示发顶到发尾，不增加卷发、辫子或参考不存在的装饰。
干净背景、单张、不带身体或文字；不重新设计脸部。
```

侧背图若由 ImageGen 推测，标记推测来源并核对同一物理侧。多视图可能产生矛盾甚至后脑重复脸；单图/多视图作为候选策略检验，不预设多图一定更好。

## 2. 三维候选和分件筛选

使用已授权工具与预算生成候选，记录实际模型/模式、部件选项、任务标识、原始下载与纹理输出。几何导出只有调试色时不能称已贴图；核验真实纹理与 UV。

采用前查看原生正/侧/背视图及逐部件 ID 图，重点找：重复脸或刘海、错侧饰品、缺后脑、熔合发团、破碎发根、异常卷曲和过大体积。无法靠小量适配修复的结构问题返回生成目标。

无损拆件并保存各自原 UV、面角、索引与材质。人工审核脸/眼/皮肤占位，最终仍使用已接受的模板脸。按发束减面后重新检查薄片、尖端和饰品；减面不等于动画重拓扑。

## 3. 静态配准

建立明确的坐标反射、朝向与左右约定。用瞳孔中心、头顶、中轴等锚点估计尺度/平移，必要时作可解释的局部变形。生成脸的眼睛可提供粗锚点，但不得因此混入最终头部。

各区分别检查：

| 区域 | 需锁定或测量的内容 |
|---|---|
| 刘海 | 正面尖端位置、分束间隙、眼睛遮挡、前后深度 |
| 脸框 | 颧/颊/下颌关系、正面轮廓、侧面贴合 |
| 后发 | 后脑完整、长度/体积、颈肩空间、发尾形状 |
| 发箍/花座/饰品 | 实际安装点、物理侧、固定部分与可动片 |
| 内层发根 | 与头皮的穿插/间隙、贴图碎斑、是否应隐藏 |

避免用大范围前推或侧壳扩宽掩盖穿插。测量原脸/头皮剖面、用 ID/深度/纯色诊断确定原因；看似穿模也可能是原纹理碎斑。局部壳修补若破坏发流或产生头盔感，应返回结构修改。

冻结接受的正面与四面结果、隐藏部件及其原因。修改可见几何后，重新验证对应脸部和物理；不要套用历史运动结论。

## 4. 按逻辑发束分组

同一束由多层碎件构成时共享骨链。不要一件网格就一条独立弹簧。按共同发根、中心线、运动方向与视觉连续性分组，单列固定头皮/发箍/花座。

先选择少量主要长发验证方法，再扩后发、脸框、刘海和饰品。每组记录源部件、发根、固定带、中心线、代理、链方向、角度/刚度和碰撞体。

## 5. 中心线、骨链与代理

在相对 Head 的正确朝向坐标系里对实际发束切片，求截面中心并平滑，按弧长布置关节。旋转过的 Head 局部 Y 不一定向上。

制作管状/带状低模代理，截面与分段数按曲率、宽度和层数选择。代理根部固定到 Head，然后连续过渡到相邻动态骨；不要直接把 Humanoid Head 当可动链根。

饰品可能从下向上生长，以真实花座/安装点为根。反射代理时同步修三角绕序与手性，防止反向法线。

## 6. 真实权重转移与连续性

求可见顶点 `p` 到本组代理表面的真正最近三角形；最近点含三角内部、边、顶点，拒绝退化三角形。按重心坐标传代理权重：

```text
w(p) = λ0*w(q0) + λ1*w(q1) + λ2*w(q2)
```

在本组内搜索，避免不同发束互串；权重归一化，限制目标平台支持的影响数，固定带为 Head=1。同位置重复角点的权重保持一致，防止裂缝。

远离代理的分层发片可能在相邻顶点间跳到远隔截面。对这些区域用沿中心线连续的纵向 station 权重场规整，或改代理覆盖；保留投影距离和相邻权重变化诊断。采用规整后应称为受约束权重场，不称纯最近点转移。

bindpose 从实际静止骨矩阵计算：

```text
bindpose_i = inverse(boneWorldRest_i) * rendererWorldRest
```

可见网格位置、法线、UV 和材质尽量保持，新增骨/权重后对比静止 BakeWorld。检查均匀缩放、反射、骨索引和局部界限；组件能初始化不证明蒙皮正确。

## 7. 三个对照

| 对照 | 内容 | 识别的问题 |
|---|---|---|
| A rigid | 原网格刚性跟 Head | 静态拟合和几何 |
| B skinned-off | 新骨/权重，物理关闭 | bindpose、静止还原、权重与固定根 |
| C physics-on | 与 B 相同，真实物理开启 | 物理参与及新增拉伸/碰撞 |

由身体/头部施加输入，SDK 独占发骨，不由观察脚本模拟弹簧。预热后逐帧记录真实 enabled/active、实际 joints 和相对各自动画锚点的运动；骨链存在不代表有响应。

测试轻转头、急转急停、点头、横向/垂直位移、静止回正，再叠加行走与蹲起。固定根检查与动态顶点检查分开。

## 8. 调参与碰撞验收

调参顺序优先为：逻辑组/根 → 代理覆盖/权重连续 → 固定带 → 角度限制 → pull/spring/immobile/gravity → 碰撞体和半径。尖刺先排权重跳变，不只靠压低运动隐藏。

刘海/脸框通常较小活动范围，后发按长度允许较大运动；发箍/花座固定。具体值按目标风格和实测选定，不沿用其他角色的链数、角度或毫米半径。

碰撞体随当前头/胸/肩位置设置，并显式核对各链引用。分别记录：

- 全帧骨段/半径到碰撞体间隙及固定根不参与碰撞的范围。
- 运动表面与实际身体/脸的穿插，而非仅骨段或稀疏顶点。
- 边长比、翻面、压缩、发束间关系和衣领/肩部间隙。
- 相对刚性对照偏移、稳定重力偏置、急停后回稳；不要混淆回到平衡与回到原 rest。

有限抽样无内部顶点不等于全帧无穿插，近似胶囊碰撞也不等于实际身体表面认证。严格接触或自碰撞未检查时明确范围。新生成身体替换后，重新摆碰撞体和复测头发。

完成静态四面、真实 A/B/C 动画与数值后，按 [validation.md](validation.md) 进入组合测试。
