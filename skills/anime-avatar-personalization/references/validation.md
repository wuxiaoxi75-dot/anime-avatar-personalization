# 验证、组合预览与交付

为当前角色建立实际证据，不继承其他角色/旧几何的通过结论。测试强度与当前任务范围匹配。主入口见 [SKILL.md](../SKILL.md)。

## 1. 三类结果分开

| 证据 | 实际检查 | 不足以推出 |
|---|---|---|
| 结构 | 网格/UV/shape/权重/bindpose/引用、保存重开、hash | 外观自然、动态无穿插 |
| 功能 | 输入值、实际骨和 shape 响应、有限坐标、复位、真实物理参与 | 目标身份相似、裙摆/睫毛美术质量 |
| 外观 | 原材质多视角及连续动作中的轮廓、遮挡、接缝、碰撞 | 未测动作、客户端或实时性能 |

单独列 `PASS / PARTIAL / FAIL / NOT RUN` 和证据路径。正常导出、SDK 组件存在、骨名正确都只是对应层的结果。

## 2. 推荐回归矩阵

| 组别 | 刺激 | 重点 |
|---|---|---|
| 脸静态 | 睁眼正面、±45°、侧面；普通/笑眼 | 五官、眼线厚度、眼白缝、悬浮、折痕/尖片 |
| 视线与闭合 | 九向视线 × 0/50/100% blink | 漏眼、遮挡、穿插、眼球枢轴/限幅 |
| 单眼/组合 | 左右单眼、双眼全闭直接进入单眼、joy+blink | 重复闭合、层覆盖、helper 归零 |
| 连续眼部 | 正常和笑眼分别连续 0→1→0 | 未拟合中间值、非单调、终点闪变 |
| 嘴眉 | 全部目标 viseme、眉毛、眨眼/视线叠加 | 嘴腔、牙齿/舌头、眉毛牵拉、恢复 |
| 头颈 | 转头、低头、仰头、侧倾 | 上口接缝、下口衣领、颈底、头发根 |
| 身体 | 行走、深蹲、蹲姿迈步、起身、举臂/屈肘 | 肢体/裙摆权重、鞋底、袖口/领口 |
| 头发 | rigid / skinned-off / SDK-on | 静止还原、真实响应、尖刺、碰撞、回稳 |
| 同时驱动 | 身体+头+视线+blink+口型+物理 | 所有权、顺序、接触与定时冲突 |

不要插入中性重置来回避已知混合过渡。隔离问题时可暂停无关物理，但最终组合测试需按本次配置真实启用并记录。

稀疏拟合键之外保留中间姿态。参考图只有正面时仍测侧面，目标缺失不能免除三维结构检查。

## 3. 原生运行与写入所有权

给每个受控对象确定写入方：Animator/平台负责面部和身体，目标物理负责发骨，观察器只采样。诊断可输入参数/眼骨目标，但不要在记录后暗改网格来制造通过。

保存实际控制器和路径；仅包装含对应曲线的 motion，检查层 mask、Write Defaults 与初始化顺序。运行时参数正确但 shape 未动、joint 存在但物理未启用，都应判相应用例失败。

保存重开后重新执行，以捕获临时场景状态、失效引用、Editor-only runtime 脚本等问题。给每次运行新标签，不覆盖旧失败。

## 4. 组合预览

使用共享时间轴协调身体、头眼、blink 和口型，采集原生连续帧；记录模拟频率、捕获频率、预热、总时长、相机和实际动作轨迹。

- 确认膝弯、髋下降、根位移和手臂动作实际发生，不能只验证 clip 名。
- 全身机位容纳手脚、裙摆、发尾，另设脸部近景；说明相机是否跟随根。
- 若有诊断鞋底/根高补偿，明确其作用，不称为真实生产 IK/foot locking。
- 使用原材质渲染，不以诊断纯色、参考贴片或生成帧冒充最终外观。
- 源帧缺失/顺序不连续时修采集；不生成中间运动掩盖缺帧。
- 保留失败姿态，例如深蹲裙摆、嘴张大或闭眼残片，不裁掉后宣称通过。

说话预览可用用户音频、普通 TTS 和近似 viseme 映射。记录事件与音频时间轴关系；若需归一化则说明。RMS 控制开口、近似元音或手写测试曲线不等于精准语音对齐。

编码后完整解码，确认分辨率/时长/帧数/音频，实际查看半闭、最大口型、深蹲、急转和结束恢复时刻。编码帧率不证明实时渲染 FPS。

## 5. 平台能力独立验收

显式测试输入驱动成功后，还需按本次交付范围接通：

| 能力 | 需验证的实际输入 |
|---|---|
| Eye Look/眼球追踪 | 平台/设备值到眼骨的枢轴、方向、限幅、复位 |
| 眨眼 | SDK 自动眨眼、单眼、joy 与新增修正进入同一有效闭合，避免双写 |
| 口型 | 实际音频/面捕、viseme 强度、静音复位与组合 |
| 物理 | 当前身体上的 SDK 骨链与碰撞体真实参与 |
| 身体 | locomotion、座姿、IK、脚底和对应追踪条件 |

眼骨按曲线移动不是实时追踪；套入音频嘴型不是平台音频桥接。未执行的部分填 NOT RUN。

若要求 PC VRChat 交付：检查当前候选 descriptor/Humanoid/视点/shader/SDK 阻断项和实际性能；固定资产 hash，执行本地 Build & Test，再在客户端同版本走、蹲、头眼/眨眼/嘴型和物理复验。新角色不能继承旧角色试穿结论。

## 6. 最终交接

交付本地工程/资产路径与 hash、实际软件/工具版本、输入和批准目标、推测项、人工标注/修权重、参数/语义计划及连续预览。给出分项结果、失败触发、证据路径和下一步。

机器计算、云端等待、人工选择、语义标注、几何/权重修复与 QA 分别计时；失败候选计入成本。模板继承、身体自动绑定和人工干预分别归因，不把人工修好的样例计作完全自动成功。

Avatar 上传/发布与本地验证分开，遵循用户本次授权。分享 skill/代码不包含模型、付费素材、输出、凭据或本地配置；用户明确授权的说明图可单独纳入相应分享范围。
